# Nebula Assault — Sprites & Assets

Todos os sprites do jogo são gerados proceduralmente via Canvas2D no arquivo `assets.js`.

## Sprites Disponíveis (SPRITES object)
| Chave | Entidade | Tamanho |
|-------|----------|---------|
| `player` | Nave do jogador | 64x64 |
| `scout` | Inimigo Scout | 48x48 |
| `fighter` | Inimigo Fighter | 48x48 |
| `heavy` | Inimigo Heavy | 56x56 |
| `elite` | Inimigo Elite | 56x56 |
| `bomber` | Inimigo Bomber | 52x52 |
| `phantom` | Inimigo Phantom | 52x52 |
| `sniper` | Inimigo Sniper | 48x48 |
| `paladin` | Inimigo Paladin | 64x64 |
| `healer` | Inimigo Healer | 52x52 |
| `boss` | Boss principal | 128x128 |
| `droneAttack` | Drone de ataque | 24x24 |
| `droneHealer` | Drone de cura | 24x24 |
| `droneCollector` | Drone coletor | 24x24 |
| `loot` | Moeda/Ouro | 16x16 |
| `powerupHeal` | Powerup cura | 32x32 |
